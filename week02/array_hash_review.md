# Week02：LeetCode 数组与哈希三题复盘

## 一、两数之和（LeetCode 1）

### 1. 题目要求

给定一个数字数组和目标值，找到两个数字，使它们相加等于目标值，返回这两个数字的下标。

例如：

- 数组：`[3, 2, 4]`
- 目标值：`6`
- 结果：`[1, 2]`

因为 2 + 4 = 6，且它们的下标是 1 和 2。

### 2. 解题思路

使用字典（dict）记录之前出现过的数字和对应下标。

遍历数组时：

1. 计算 `needed_number = target_sum - number`。
2. 查看字典中有没有 `needed_number`。
3. 如果存在，返回两个数字的下标。
4. 如果不存在，就将当前数字及下标放进字典。

### 3. 核心知识点

- `dict`：字典，用于根据键快速找到值。
- `enumerate()`：遍历时同时获得下标和元素。
- `in`：检查某个键是否存在。
- `return`：返回结果并结束函数。

### 4. 为什么使用字典？

因为字典可以快速查找之前出现过的数字，不需要每次重新遍历整个数组。

平均时间复杂度：O(n)。

额外空间复杂度：O(n)。

### 5. 容易犯的错误

- 返回数字本身，而不是下标。
- 忘记 Python 的下标从 0 开始。
- 在检查之前就保存当前数字，可能造成同一个元素被使用两次。

## 二、字母异位词分组（LeetCode 49）

### 1. 题目要求

将字母相同、排列顺序不同的单词分到一组。

例如：

输入：

`["eat", "tea", "tan", "ate", "nat", "bat"]`

输出：

`[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]`

### 2. 解题思路

使用排序和字典完成分组。

1. 使用 `sorted()` 对单词的字母排序。
2. 使用 `"".join()` 把排序后的字母拼接成字符串。
3. 将这个字符串作为字典的键。
4. 排序结果相同的单词放进同一个列表。
5. 最后返回字典中的所有分组。

例如：

- `eat` 排序后是 `aet`。
- `tea` 排序后是 `aet`。
- `ate` 排序后也是 `aet`。

所以三个单词属于同一组。

### 3. 核心知识点

- `sorted()`：对字符进行排序，返回列表。
- `join()`：把多个字符拼接成字符串。
- `dict`：使用相同的键管理同一组单词。
- `append()`：把元素添加到列表末尾。
- `values()`：获取字典中的所有值。

### 4. 为什么先排序？

因为不同顺序的字母经过排序后，可以形成相同的标识。

利用这个标识，就能快速把同类单词分到一起。

### 5. 容易犯的错误

- 直接比较原始单词。
- 忘记排序后还需要拼接。
- 忘记创建新的分组列表。
- 不小心把不同分组的单词放在一起。

## 三、最长连续序列（LeetCode 128）

### 1. 题目要求

给定一个乱序整数数组，找到最长连续整数序列的长度。

例如：

输入：`[100, 4, 200, 1, 3, 2]`

最长连续序列：`[1, 2, 3, 4]`

结果：`4`

另一个例子：

输入：`[5, 6, 7, 100, 101]`

最长连续序列：`[5, 6, 7]`

结果：`3`

### 2. 解题思路

使用集合（set）快速查找数字。

1. 使用 `set(numbers)` 把数组转换为集合，去除重复数字。
2. 遍历集合中的数字。
3. 检查当前数字减 1 是否存在。
4. 如果存在，说明当前数字不是序列起点，用 `continue` 跳过。
5. 如果不存在，说明当前数字可能是起点。
6. 使用 `while` 不断检查下一个数字是否存在。
7. 统计当前序列长度。
8. 使用 `max()` 保留最大的长度。

### 3. 为什么要判断前一个数字？

例如有数字 `[1, 2, 3, 4]`。

- 检查 1：没有 0，所以从 1 开始计算。
- 检查 2：存在 1，说明 2 不是起点，跳过。
- 检查 3：存在 2，跳过。
- 检查 4：存在 3，跳过。

这样可以避免重复统计连续序列。

### 4. 核心知识点

- `set()`：创建集合，自动去除重复元素。
- `for`：遍历集合中的所有数字。
- `if`：判断条件是否成立。
- `continue`：跳过当前这次循环。
- `while`：条件满足时继续执行。
- `max()`：选出两个数中的较大值。

### 5. 为什么使用集合？

因为集合可以快速判断数字是否存在。

配合只从序列起点开始计数的策略，可以避免重复计算。

平均时间复杂度：O(n)。

额外空间复杂度：O(n)。

### 6. 容易犯的错误

- 把不连续的数字算成同一段。
- 忘记判断当前数字是不是起点。
- 混淆 `continue` 和 `break`。
- 把最长连续序列的长度理解为最大数字与最小数字的差。

## 五、三个算法的核心区别

**两数之和：** 使用字典快速寻找另一个数字。

**字母异位词分组：** 使用排序后的字符串作为字典的键，将同类单词放在一起。

**最长连续序列：** 使用集合查找连续数字，只从序列起点开始计数。
